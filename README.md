# 오늘뭐먹지

한식·양식·일식·분식 중 음식 종류와 매운맛 선호에 맞는 메뉴를 추천하는 서비스입니다.

- 배포: https://gitdevtori.github.io/iscu-uiuxprogramming/
- 저장소: https://github.com/gitdevtori/iscu-uiuxprogramming
- 사용 기술: HTML, CSS, JavaScript

## 중간고사 추가 기능

7주차 추천 결과에 찜하기·다시 보기·찜 해제를 추가해, 마음에 드는 메뉴를 저장하고 다음 식사 때 다시 확인할 수 있습니다.

## 사용자와 목적

- 사용자: 식사 메뉴를 정하기 어려운 학생·직장인
- 목표: 취향에 맞는 메뉴를 빠르게 찾아 고민 시간 줄이기
- 핵심 행동: 취향 선택 → 메뉴 추천 → 찜하기·다시 보기
- 완료 조건: 찜한 메뉴와 저장 당시 선택값 확인

## 사용자 흐름

**시작 → 취향 선택 → 선택 확인 → 추천 완료**

**중간고사: 추천 완료 → 찜하기 → 찜 목록 → 다시 보기 / 찜 해제**

이전 단계로 돌아가면 선택값을 유지하고, 다시 시작하면 현재 추천만 초기화합니다.
찜 목록은 같은 브라우저에 저장되어 새로고침하거나 다시 시작해도 유지됩니다.

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
|---|---|---|---|---|
| 추천 시작 | click | 시작 화면 | 선택 화면 표시 | 취향 선택 |
| 다음 | submit | 필수 선택 누락 | 오류와 수정 방법 안내 | 선택 유지 |
| 다음 | submit | 선택 완료 | 최신 선택값 요약 | 확인 |
| 이전 / 수정하기 | click | 선택 / 확인 화면 | 값 유지 | 이전 단계 |
| 추천받기 | click | 추천 메뉴 있음 | 메뉴와 완료 문구 표시 | 완료 |
| 추천받기 | click | 추천 메뉴 없음 | 조건 변경 안내 | 확인 유지 |
| 이메일 입력 | input | 형식 오류 / 정상 | 오류 표시 / 버튼 활성화 | 완료 유지 |
| 이메일로 추천받기 | submit | 정상 이메일 | 입력 완료 표시 | 완료 유지 |
| 다시 시작 | click | 완료 화면 | 현재 추천 초기화, 찜 목록 유지 | 시작 |

## 중간고사 기능추가 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 행동 |
|---|---|---|---|---|
| 찜하기 | click | 저장하지 않은 메뉴 | 메뉴·선택값 저장, 완료 안내 | 찜 목록 보기 |
| 같은 메뉴 추천 | click | 이미 찜한 메뉴 | 찜 버튼 비활성화 | 다시 보기 |
| 다시 보기 | click | 저장된 메뉴 | 당시 메뉴·선택값 표시 | 목록으로 돌아가기 |
| 찜 해제 | click | 저장된 메뉴 | 해당 항목 제거, 개수 갱신 | 다른 메뉴 확인 / 다시 찜하기 |
| 마지막 메뉴 해제 | click | 한 개만 남음 | 빈 목록 안내 | 메뉴 추천받기 |
| 찜하기 / 해제 | click | 저장 실패 | 목록 유지, 오류 안내 | 설정 확인 후 재시도 |
| 페이지 열기 | load | 저장 데이터 오류 | 오류 안내, 빈 목록 표시 | 메뉴 다시 찜하기 |
