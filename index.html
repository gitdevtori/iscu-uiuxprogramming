주요 기능

  • 메뉴 추천

    선택한 취향을 바탕으로 먹을 메뉴를 추천합니다.

  • 취향 반영

    한식, 양식, 일식, 분식 중 원하는 음식 종류를 선택할 수 있습니다.

  • 간단한 이용

    복잡한 과정 없이 간단한 선택만으로 이용할 수 있습니다.

이용 방법

  1. 추천 시작 버튼을 눌러 메뉴 추천을 시작합니다.
  2. 원하는 음식 종류와 매운맛 선호를 선택합니다.
  3. 선택한 내용을 확인하고 추천받기 버튼을 누릅니다.
  4. 추천된 메뉴를 확인합니다. 다시 고르고 싶다면 다시 시작을 누릅니다.
